## 关于「歌单链接」

网易云的歌单链接只能由登录账号创建（`https://music.163.com/playlist?id=xxxx`），没有把文本直接转成链接的公开接口。所以这里给的是可批量识别的清单：

1. 复制 `歌单_批量导入.txt`，粘进「文本转歌单」工具 / 小程序，一次建单。
2. 手机端「我的 → 导入外部歌单」可贴其他平台链接；文本转歌单建议用第三方迁移工具（如 TestMusic）。
3. 兜底：打开 `index.html` 逐首点开单曲页手动加，124 首大约 10 分钟。

## 选盘说明

- **Nujabes** 取《modal soul》而不是《Metaphorical Music》：前者更能代表 Hydeout 的完整班底（Shing02、Uyama Hiroto、Substantial、Cise Starr 都在）。
- **二宮愛** 取 2016 年原创专辑《Finding Stride》；她与 Hidetake Takayama 组成的 FLY COAST 另有一张《Flight Number 001》，想要组合时期可以换。
- **BLU-SWING** 取出道作《Jazzyster》（2007），后续《Secret Of Attraction》《TRANSIT》更偏 club jazz。
- **jazz pop 的欧美一侧**刻意选了 70–80 年代的 sophisti-pop / jazz-pop 源头（Michael Franks、Sade、Basia、Matt Bianco），再补 Norah Jones、Diana Krall、Laufey 三个不同世代。
- **华语**只留了蛋堡《收敛水》和 Lu1《男孩》，一旧一新。
- 蛋堡在网易云登记为「蛋堡」（别名 Soft Lipa）；`蛋堡` 的歌名含繁体/简体混排，批量匹配时保持原样即可。
