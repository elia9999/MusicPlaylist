## 选盘说明

- **前史（01–03）**：JAMC《Psychocandy》、Cocteau Twins《Heaven or Las Vegas》、Spacemen 3《The Perfect Prescription》。严格说不是盯鞋，但没有它们就没有盯鞋。
- **第一波（04–15）**：Ride《Nowhere》、Slowdive《Souvlaki》、Lush《Spooky》、Chapterhouse《Whirlpool》、Swervedriver《Raise》、Catherine Wheel《Ferment》、Pale Saints、Curve、The Verve、Boo Radleys、Telescopes。
- **美国线（16–22）**：Drop Nineteens、Swirlies、Lilys 三支 90 年代乐队，加 Ringo Deathstarr、Nothing、Whirr、DIIV 四支复兴 / 当代。
- **日本线（23–25）**：東京酒吐座、Luminous Orange、Cruyff In The Bedroom。
- **华语（26–27）**：缺省《California Nebula》、发光曲线《迷航》。
- **其余（28–30）**：Pinkshinyultrablast（俄罗斯）、Serena Maneesh（挪威）、No Joy（加拿大）。
- `Loveless` 与 emo/盯鞋那份歌单重复，是刻意的——它单独值得出现在这里。

## 关于歌单链接

网易云歌单链接只能由登录账号创建（`https://music.163.com/playlist?id=xxxx`），没有文本直出链接的公开接口。复制 txt 去批量识别，或用 `index.html` 逐首手动加。
